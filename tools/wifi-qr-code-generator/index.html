Wi-Fi QR code generator

Type your network name and password. Guests scan the code and connect, with no typing.

Private by design: your files are processed on your device and are never sent to our servers.

Instead of reading out a long Wi-Fi password, put a QR code on the wall, the fridge or the shop counter. Phone cameras read it and offer to join the network.

The ScanOrbit app makes the same Wi-Fi codes, and can also scan one to copy the password.

How to use

  1. Type the Wi-Fi name exactly as it appears on phones.
  2. Type the password. Leave it empty for an open network.
  3. Download the QR code and print or share it.

Tips

  • Names and passwords are case-sensitive, so copy them carefully.
  • If you change the router password later, make a new code.
  • Keep the printed code where guests can see it, but not outside your home or shop.

Questions

How do I make a QR code for my Wi-Fi?

Choose Wi-Fi, type the network name and password, and download the code. Guests scan it with their phone camera to join.

Does it work on iPhone and Android?

Yes. Current iPhone and Android cameras can read Wi-Fi QR codes.

Is my Wi-Fi password sent to your server?

No. The code is made in your browser and the password never leaves your device.

What if my network has no password?

Leave the password box empty and the code will be made for an open network.
