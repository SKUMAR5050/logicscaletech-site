A WhatsApp link opens a chat with your number in one tap. Put it on your website, Instagram bio, Google Business Profile or a printed poster, so customers can message you without saving your number first.

You can also add a ready message, so the chat opens with the text already typed. For example, a shop can use "Hi, I want to order a cake".

How to use

  1. Check the country code. 91 is for India.
  2. Type the number without spaces, dashes or the country code.
  3. Add a message if you want one, then copy the link or download the QR code.

Tips

  • Use a number that is on WhatsApp. The link cannot check this for you.
  • A short message works best. Customers can edit it before sending.
  • Test the link on your own phone before you print the QR code.

Questions

How do I make a WhatsApp link?

Enter the country code and your number, and the tool builds a link that starts with https://wa.me/. Anyone who opens it can start a chat with you.

Do I add the plus sign or zeros?

No. Use only digits. For an Indian number, use 91 as the country code and the 10-digit number without a leading zero.

Can the message be filled in already?

Yes. Type it in the message box. The chat opens with that text ready to send.

Is it free? Do you store my number?

It is free, with no sign-up. The link and QR code are made in your browser, and your number is not sent to our servers.
